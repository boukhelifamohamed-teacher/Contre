# تسيير الاختبارات الفصلية — Android

نسخة Android من ملف HTML مع واجهة واسعة شبيهة بالكمبيوتر.

## إصلاح الطباعة
تم إصلاح مشكلة عدم ظهور أمر الطباعة داخل APK. التطبيق يستخدم الآن Android Print Framework عبر `cordova-plugin-printer` بدل الاعتماد على `window.print()` الذي لا يفتح نافذة الطباعة في WebView كما في المتصفح.

عند الضغط على أي زر طباعة، مثل:
- طباعة جدول الحراسة
- طباعة الفترة
- طباعة كل الفترات
- طباعة الغائبين
- طباعة بطاقات الحراسة

ستظهر نافذة الطباعة الخاصة بنظام Android، ويمكن اختيار الطابعة أو Save as PDF إذا كانت خدمة الطباعة متاحة على الهاتف.

## البناء من GitHub
1. ارفع محتويات هذا المجلد إلى المستودع.
2. افتح Actions.
3. اختر Build Android APK.
4. اضغط Run workflow.
5. حمّل Artifact باسم `Tasyir-Alikhtibarat-Android`.

تم أيضًا إزالة `cache: npm` من إعداد Node حتى لا يتكرر خطأ `Dependencies lock file is not found`.
