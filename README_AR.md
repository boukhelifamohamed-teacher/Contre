# تسيير الاختبارات الفصلية — Android

هذا المشروع يحوّل ملف HTML إلى تطبيق Android باستعمال Cordova وGitHub Actions.

## ما تم تعديله
- فتح ملف HTML داخل WebView كتطبيق Android.
- تفعيل **واجهة سطح مكتب**: عرض واسع قريب من الكمبيوتر بدل إعادة ترتيب العناصر إلى واجهة هاتف ضيقة.
- التطبيق يعمل بالعرض الأفقي (Landscape) لتسهيل الجداول.
- السماح بالتكبير والتصغير باللمس.
- الاحتفاظ بـ `localStorage` الخاص بملف HTML.
- إضافة شعار المؤسسة المرفق كأيقونة للتطبيق.
- إنشاء APK تلقائيًا من GitHub Actions.

## البناء من الهاتف
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع جميع ملفات هذا المشروع.
3. افتح `Actions`.
4. اختر `Build Android APK`.
5. اضغط `Run workflow`.
6. بعد انتهاء البناء، افتح `Artifacts` وحمّل `Tasyir-Alikhtibarat-Android`.
7. استخرج ملف `Tasyir-Alikhtibarat.apk` وثبته على Android.
